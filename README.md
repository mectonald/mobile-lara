# mobile lara

Um diário noturno interativo feito para a Lara. É um site estático de um arquivo só (`index.html`), pensado para celular.

## Ver

Abra `index.html` no navegador, ou ative o GitHub Pages (Settings → Pages → branch `main`, pasta `/`).

## Personalizar

Todos os textos ficam no objeto `CONTEUDO`, no começo do `<script>` em `index.html`. As lembranças reais entram em `CONTEUDO.lembrancas` (`frente` aparece fechado, `dentro` ao tocar).

# mobile lara

Um caderninho de bolso feito para a Lara, com clima de mato e um campinho de capivaras. É um site estático de um arquivo só (`index.html`), pensado para celular.

## Ver

Abra `index.html` no navegador, ou ative o GitHub Pages (Settings → Pages → branch `main`, pasta `/`).

## Personalizar

Todos os textos ficam no objeto `T`, no começo do `<script>` em `index.html`. As lembranças reais entram em `T.arquivo.itens` (`titulo` aparece fechado, `texto` ao abrir; `branco:true` vira uma gaveta vazia de propósito).

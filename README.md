# mobile lara

Um bom dia interativo feito para a Lara. É um site estático de um arquivo só (`index.html`), pensado para celular: o céu amanhece no mato conforme ela desce a página, com capivaras, um pote de bilhetes e uma lista que não cobra nada.

A versão anterior (o caderno em capítulos) está em `caderno/index.html`.

## Ver

Abra `index.html` no navegador, ou ative o GitHub Pages (Settings → Pages → branch `main`, pasta `/`).

## Personalizar

Todos os textos ficam no objeto `T`, no começo do `<script>`. Os bilhetes do pote estão em `T.bilhetes` (é só acrescentar frases na lista); a lista do dia em `T.lista`; os bichos e as fichas em `T.campo_motor.especies`.
